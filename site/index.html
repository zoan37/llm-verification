llm-verification · black-box audit

Is each provider serving the model it lists?

Every OpenRouter endpoint of a model got the same prompts. A referee running the real weights replayed each reply and measured how well it fits. Rows sit on a scale from an honest machine running those weights (100) to a known substitute (0).

Fidelity

100 = as close to the referee as an honest second machine; 0 = as far as the substitute named for that model. Linear in log distance, clipped. A ranking aid; the distance and its interval are the evidence.

Regret (greedy)

At temperature 0, how much less likely the referee found the provider's chosen token than its own first choice, in nats per token. 0 means the same token. Bar: 95% interval, ticks at the honest and substitute levels.

Sampled fit (PIT)

At temperature 1, where each sampled token falls in the referee's distribution: 0.500 on average for true samples, needing no calibration. Above 0.5 means less likely tokens than the real model would pick. * marks p < 0.001. "tail" is long-tail draws (p < 1e-4) observed vs expected: honest sampling is near 1×, a silent top-k is near 0×, a flatter substitute model is well above 1×.

Peer agreement

How long an endpoint's temperature-0 replies stay identical to the other endpoints', as a share of the first 200 characters (median over peers). Needs no reference weights, but it rewards being like the crowd, not being correct.

Self-PIT

Referee-free check that an endpoint's reported logprobs describe its own temperature-1 samples: 0.500 when they do. Far from 0.5 means the logprobs and the sampler disagree.

Flags

Integrity findings that are not about model identity: sampling when asked for temperature 0, dropped output tokens, prompt token counts that disagree with the published template, no logprobs.

A low score is not proof of cheating. Honest serving choices (FP8 weights, an FP8 KV cache, different kernels) move outputs too, and a provider can behave differently for audit traffic than for yours. A high score means the replies we got are statistically consistent with the real model at this sample size. What the checks can and cannot prove is in docs/soundness.md.
